# Assignment Bridge API

Backend for **Assignment Bridge** — a platform where university students post
their assignments and get help from verified experts.

Three roles: `STUDENT`, `EXPERT`, `ADMIN`.

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run dev
```

This project was created using `bun init` in bun v1.4.0. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
